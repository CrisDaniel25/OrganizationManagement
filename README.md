# Organization Management

Multi-tenant organization administration solution with an Angular client and an ASP.NET Core backend. It covers client workspaces, employee administration, roles, audit history and reusable dynamic UI components.

## Portfolio demo

The `portfolio-demo` branch adds a safe, self-contained browser demo using fictional data. It presents organization and employee management, role-based permissions, audit events and a simulated Microsoft Entra ID / OpenID Connect configuration. Demo mutations are temporary and no production service, credential or customer data is used.

## Original solution

- Angular administrative client
- ASP.NET Core API
- Domain and Infrastructure layers
- JWT authentication and role-based access controls
- Dynamic forms, grids and reusable components
- Docker support
